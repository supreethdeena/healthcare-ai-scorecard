# Healthcare AI Leadership Archetype Scorecard POC

A static, browser-based prototype for Healthcare Unstructured. No backend, database, or personal data collection.

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a new GitHub repository, for example `healthcare-ai-scorecard`.
2. Upload `index.html` and `script.js` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to provide the public URL.

## Before publishing
- Replace the community button alert in `script.js` with your LinkedIn community URL.
- Review question wording and archetype bands with healthcare leaders.
- The current overall-score bands are provisional and are not validated.
- This prototype does not collect or transmit answers.
